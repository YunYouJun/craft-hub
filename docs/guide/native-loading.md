# 原生页面的加载反馈

项目详情和软件目录首次读取时保留页面导航与工具栏，超过 200 ms 再显示静态骨架。快速读取直接显示结果。项目骨架对应概览与能力列表，软件骨架复用真实目录的自适应网格列；占位不提供可点击控件、虚构的软件数量或项目信任状态。

已有内容时，刷新继续显示真实数据与当前搜索、筛选，只在标题或计数旁延迟显示小型进度指示。读取失败结束加载并显示实际错误；已有快照继续保留。项目能力的过期标记及审阅限制沿用既有状态模型。首次软件读取不再提前显示 `0 / 0`，首次项目读取也不会提前显示“项目暂不可用”。

骨架使用系统语义色，没有扫光动画或重复计时器。反馈只使用一次可取消的延迟；读取完成或离开页面后结束。占位形状不进入辅助功能子树，只暴露页面的读取说明。下载、安装、环境检查及 Node 启动继续使用各自的真实进度和错误反馈。

这次修改只涉及视图，不改变持久化、插件读取策略、运行时权限或 WKWebView 生命周期；草稿与历史仍由现有持久化流程管理。它改善等待反馈，不代表后端更快，也不构成驻留内存、空闲 CPU 或唤醒次数下降的证据。
