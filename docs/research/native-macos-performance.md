## Electron 交互采样接线（2026-10-23）

当 Electron 的 `CRAFT_HUB_PERFORMANCE_TRACE` 为绝对路径时，网页就绪后宿主启用采样并写出 `interaction-trace-ready`。普通浏览器和未启用的桌面会话不读取交互时钟。命令面板记录打开状态变更到真实搜索框获得焦点并完成 Vue flush；页面记录路由守卫到目标组件 mounted/updated 并完成 Vue flush。取消导航或关闭尚未就绪的面板产生 `cancelled`，不能混入完成样本。

### Instruments 启动采集与限制

对同一批产物的独立副本分别运行一次 Xcode 27.1 的 `App Launch` 模板，限时 10 秒，导出 `life-cycle-period`。报告及原始 trace 保存在 `apps/macos/build/instruments-20261023-candidate/`。原生记录具有有限的 `Launching - Initial Frame Rendering` 区间：持续 **108.96 ms**，在 trace 的 642.96–751.93 ms；该坐标从 Instruments 记录开始，不是 Launch Services 请求时刻，也不证明此时已经可点击。

Electron 已发出窗口和网页就绪事件，但 App Launch 的三段生命周期 duration 导出为 `18446744073709551615`、显示格式为 `-`，没有有限的 Initial Frame Rendering 区间。报告将这些值记为不可用，不能换算成零或与原生比较。两次采集均因 `time-sample` 1 ms / 5 ms 绑定不一致发出警告，`xctrace record` 返回 54；生命周期 XML 可导出，但本次不使用 CPU 样本推导性能结论，也不把整份采集标记为无警告通过。

## 复现

先构建当前原生包和相同源码的 Electron arm64 包，再执行：

```sh
pnpm build:macos
pnpm -C apps/desktop build
CRAFT_HUB_DESKTOP_OUTPUT_DIR=apps/macos/build/electron-baseline node --import tsx --input-type=module -e 'import { packageMacos } from "./scripts/package-macos.ts"; await packageMacos({ architectures: ["arm64"], createArtifacts: false, adHoc: true, codexMode: "external" })'
pnpm benchmark:macos --electron 'apps/macos/build/electron-baseline/Craft Hub-darwin-arm64/Craft Hub.app' --iterations 3 --output apps/macos/build/performance-new-run
```

每次选择新的 `--output` 目录；存在 `report.json` 时脚本拒绝覆盖。输出包含 report、逐次 trace 和原始 footprint，记录源码 revision/dirty、原始产物签名、Node、机器、就绪标记、进程归属、采样完整性与清理结果。迭代失败也保留已有结果；`completed` 只表示启动迭代完成，仍须检查各次 `memory.complete` 和 cleanup。文件位于忽略的构建目录，不提交机器路径与状态。脚本只清理本次独立副本中身份仍匹配的进程，保留未退出进程的临时资料，不按进程名结束其他应用，也不直接强制终止 Apple XPC 服务。

原生 `Performance` 日志类别提供固定事件名的 Logger/signpost；`./script/build_and_run.sh --telemetry` 可观察。`CRAFT_HUB_PERFORMANCE_TRACE` 指定绝对路径时额外写本机 JSON，不包含 token、项目内容或探测输出。`CRAFT_HUB_NATIVE_DATA_DIR` 隔离运行时、草稿和偏好；Electron 对照使用 `CRAFT_HUB_DATA_DIR` 加 `CRAFT_HUB_DESKTOP_PROFILE_DIR`。这些是开发验收入口，不是数据迁移操作。
