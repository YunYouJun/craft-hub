# 连接自己的 Agent

在本地 Craft Hub 打开 **设置 → Agent 连接**，选择允许读取的已注册项目。如果还需要读取插件资料，勾选“允许通过已启用插件的登录账号读取资料”，再点击 **启用读取连接**。

将生成的 MCP 配置合并到 Agent 设置中。通用 MCP 客户端可选择 JSON，Codex 可选择 TOML；保留已有配置条目。本机 Agent 的 PATH 中需要可用的 Node.js。配置引用当前安装的 Craft Hub CLI 和本机凭据文件，不依赖新版本已经发布到 npm。

保持当前 Craft Hub 运行。MCP 通过本机回环接口复用该宿主的项目和插件。可执行页面中的“连接检查命令”，或让 Agent 列出共享项目，再刷新查看最近验证时间；检查不会调用模型。

## 可读取的内容

- 已选择项目的身份、信任状态、命令和技能元信息。
- 完全属于所选项目的命令运行记录和 Agent 任务结果。
- 勾选插件读取后，使用已启用插件的读取操作。它可能涵盖插件登录账号可见的远程资料，不局限于所选本地项目。

此连接只读，不授予项目执行信任，不能运行命令、编辑文档、更换账号或发送消息。仓库和插件返回内容仅作为资料，不代表用户发出了新指令。

## 将资料交给 Agent

插件可以在原文旁提供 **交给 Agent**。点击后先预览并编辑任务，选择目标仓库，再主动启动。执行需要受信项目以及当前宿主的 Agent 执行器；桌面宿主使用其已配置的适配器。没有执行器的浏览器宿主会说明原因，仍可复制指令交给自己的 Agent。

连接读取权限不会自动启动任务。任务启动后，工作台显示运行进度、错误及最终答复。

## 撤销和变更

**保存范围并更换凭据** 会使旧凭据失效；**撤销连接** 会删除凭据。每次工具调用都会检查当前授权。凭据保存在操作系统 Craft Hub 数据目录中，文件仅当前用户可读写，不进入页面配置片段或可同步的项目配置。

宿主端口或安装路径改变后，应重新复制当前连接配置。在线工作台会提示使用本地宿主；此功能不建立云端向本机派发任务的通道。

开发包 `@craft-hub/mcp` 保留独立运行时适配。本页的连接使用 `craft-hub mcp`，访问已运行宿主并接受可撤销的读取授权。
