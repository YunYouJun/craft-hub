# 查看 Codex 插件配置

桌面版内置 `@craft-hub/craft-hub-plugin-codex` Host Plugin。在工作台侧栏打开 **Codex**，选择项目后可查看该项目的覆盖配置；未选择项目时显示全局配置。点击刷新获取最新快照。

每个插件显示安装版本、全局配置、项目覆盖和生效来源。全局关闭但项目开启的插件会同时展示两层设置。项目配置被 Codex 忽略时会显示提示；市场读取失败时不会把缺失条目直接判定为未安装。

这是插件层的配置状态，并不等于每个 Skill、MCP 工具都已可用。单独的技能禁用、MCP 配置、账号权限和组织策略仍可能限制能力。已有任务不会因刷新自动重新加载插件。

本插件调用本机 Codex 的配置和插件 API，支持通过明确的开关操作修改配置，不安装插件或执行任务。界面不会收到完整配置或凭据。Codex 自身的市场查询可能访问远程服务及更新缓存。本功能依赖支持相关 app-server API 的 Codex CLI 或桌面应用。

浏览器模式可显式加载已构建的 Host Plugin：

```sh
pnpm --filter craft-hub start ui --host-plugin /absolute/path/to/craft-hub/packages/craft-hub-plugin-codex/dist/index.mjs
```

该插件是 Craft Hub 中查看 Codex 的集成，与在 Codex 中操作 Craft Hub 的同名方向相反的插件独立。

界面跟随工作台的中英文语言设置。全局来源、项目覆盖和生效来源支持点击：桌面版使用工作台配置的编辑器；浏览器版使用 VS Code 协议链接，需要本机安装 VS Code。点击来源链接不会改变插件启用状态。

启用配置每次刷新都会实时读取。安装目录在内存中缓存最多一分钟，并按全局／项目分别保存；首次访问仍需等待目录查询，之后短时间内刷新或打开配置来源可复用目录。手动刷新列表时安装信息最多缓存一分钟。切换开关仅更新本地配置，不等待插件目录查询，安装信息沿用上次列表结果。失败或不完整的目录不缓存。

首次进入或切换范围时，先展示实时配置，并标注“正在核对安装信息”；安装名称和版本随后补齐。优先使用仅返回已安装插件的 `plugin/installed` 接口；只有旧版 Codex 不支持此接口时才回退完整市场查询。

## 快捷开启与关闭

先选择配置范围，再点击每行的“全局开关”或“项目开关”。项目中点击“跟随上层设置”只删除当前项目的启用覆盖；父目录项目的配置仍可能继续生效。安装信息加载完成后才显示开关，保存期间不能重复点击。被 Codex 忽略的项目配置不会开放开关。

写入由后端根据已登记项目选择配置文件，并检查文件版本，避免覆盖刷新后产生的修改。使用临时隔离目录中的 Codex TOML 编辑器保留注释与其他字段，再替换目标文件；不更改项目的信任状态。保存后重新读取本地配置，复用已加载的安装信息；失败时请刷新核对结果再重试。已有 Codex 任务可能需要重新打开才能加载变更。

开关通过位置和颜色表达开启／关闭，旁边不再重复显示状态文字。保存时在开关内显示进度；项目范围保留“已跟随上层设置”提示或“跟随上层设置”按钮。
