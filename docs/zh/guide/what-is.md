# Craft Hub 是什么？

Craft Hub 是个人软件与开发环境工作台。新的定位围绕软件准备、日常工具入口、环境检查和可审阅的配置迁移。当前 alpha 已有个人总览、本机工具检测、项目能力、工具交接和配置审阅；软件安装、换机向导与环境就绪首页仍待实现。

Raycast 负责快捷操作和扩展命令；Orca 或你选择的编程工作台负责 Agent 会话、工作树、终端和代码审阅。Craft Hub 拟让首页回答：装了什么、缺什么、环境是否可用、下一步该做什么。Workstation 继续负责配置审阅与同步；按软件选择安装和项目环境要求检查还需要补接口。参见[个人环境工作台路线](../../design/machine-workbench-direction.md)。

打开 **本机环境**（`/environment`），可以检查本地 API 宿主上的 Git、Node.js、pnpm、fnm、Homebrew 与 Workstation，查看版本、可执行路径、来源与逐项失败原因；后台 Node 会单独展示。检查只在打开环境页或手动刷新时运行。“未发现”表示当前工作台的搜索位置未找到；Hosted 工作台无法检测浏览器用户的电脑。软件安装仍待实现。

当前 `/overview` 仍汇总不同来源的工作事项和本机项目上下文。这些视图会保留，作为环境工作台中的辅助入口。

总览通过已声明的只读 `work-items.list` 操作，预览真实分配给你的未完成事项。来源账号、加载失败分别展示，部分结果会标注为预览。状态更新仍在对应集成页面中处理，保留必填字段、校验和确认。Craft Hub 不另建任务数据库。

在事项或项目旁选择 **准备交接**，明确选择本机项目，补充本次目标，再预览并复制上下文。在外部工具中粘贴后开始工作。打开应用不会自动提交任务、证明上下文已被接收，或修改来源系统的状态。

工具入口保留 HTTPS 网站地址。在 macOS 桌面端，可选择 Raycast 或 Orca 应用预设；Raycast 也可打开从已安装命令复制的命令深层链接。首版不接受链接参数和其他协议。已配置的 Raycast 命令可能执行自身操作，但交接上下文不会自动传入。Orca 仅启动应用，不传项目或提示词。浏览器模式打开网站，应用启动失败会明确提示已回退到网站。这些应用都不是 runtime 的必需依赖。

个人总览设置保存在操作系统 Craft Hub 数据目录的 `settings.json` 中，对应 `workbench.home`。工具设置和项目收藏可在重启后保留。项目 ID 与本机路径有关，因此便携配置导出当前不包含这个设置。

Project Palette 继续只读发现仓库命令与 Skills；执行结构化命令仍需明确的项目信任。配置审阅、诊断、CLI、本地 API、MCP 和可选 Electron 宿主共用 runtime。迁移期间保留已有内部任务调用方；Agent connection 当前提供按范围授权的只读访问，尚未开放命令执行和业务写操作。
