| 在命令面板里输入 | 每次按键在同一帧内更新本地结果；远端结果不阻塞输入 | Instruments 帧时间 |
| 侧栏切换页面 | ≤ 100 ms 出现目标页结构，数据随后填充 | signpost |
| 拖动改变窗口大小 | 内容不滞后、不露白边 | 录屏逐帧检查 |

### 系统行为一致

- [ ] **窗口：** 记住位置和大小，支持全屏和多显示器；关闭最后一个窗口时按 macOS 惯例保留应用和菜单栏入口。
- [ ] **键盘：** 主流程能只用键盘完成；侧栏可用方向键移动；有标准菜单项和快捷键（⌘, 打开设置、⌘W、⌘F 等）；Esc 关闭面板和弹层。
- [ ] **菜单：** 应用菜单、右键菜单和 Dock 菜单都是原生菜单。
- [ ] **文字输入：** 中文输入法的候选框位置正确，支持撤销、重做和拼写检查。
- [ ] **拖放：** 把文件夹拖到侧栏或 Dock 图标上即添加项目，新项目仍为 `untrusted`。
- [ ] **外观：** 跟随系统的深浅色和强调色；遵守“减少透明度”“减少动态效果”“增强对比度”。
- [ ] **无障碍：** VoiceOver 能读出全部控件，焦点顺序与视觉顺序一致。

### 系统入口

- [ ] **菜单栏：** 常驻入口显示今日重点、快速记录和最近项目。
- [x] **全局快速记录：** 不用切换到主窗口就能记录。2026-10-22 用户真实键盘复核通过。
- [ ] **App Intents：** 提供“打开项目”和“快速记录”，可在快捷指令和 Spotlight 中使用。
- [ ] **通知：** 带操作按钮，但只能打开对应页面，不能授予信任或运行命令。
- [ ] **深链接：** `craft-hub:` 继续只做导航，见 [ADR 0007](../adr/0007-keep-desktop-links-navigation-only.md)。

### 可靠性与安全

- [x] 运行时辅助进程崩溃后自动重启，界面显示状态，未保存的快速记录不丢失。2026-10-22 Release App 强制终止辅助进程后复核通过。
- [ ] 正常退出和强制退出后都不残留 Node 进程。
- [ ] 优先使用本机已有的兼容 Node；诊断中心显示当前使用的 Node 路径和版本。用户升级或删除 Node 后，下次启动自动重新选择并提示。
- [ ] 固定规则找不到兼容 Node 时，引导页提供“从登录 shell 读取 PATH”按钮，照顾只靠 shell 启动文件配置的 nvm、Volta、asdf、mise。只有用户点击才会运行，启动时从不自动运行。运行一次登录 shell，非交互并设超时，只读取 `PATH`。找到的 Node 同样做兼容检查，并保存为用户指定路径，之后不再运行 shell。按钮旁说明这会执行用户的 shell 启动文件。
- [ ] 没有兼容 Node 时，原生引导页仍能打开并说明原因，满足 [ADR 0011](../adr/0011-focus-on-machine-setup-and-environment.md)。用户确认后才下载 Craft Hub 私有 Node 并校验官方 checksum；不修改用户自己的 Node 或 `PATH`。
- [ ] 原生端不执行项目命令。新项目仍为 `untrusted`，执行仍走运行时的显式信任和 `shell: false`；快捷指令、通知和菜单栏入口都不能绕过应用内确认。

## 不在本目标内

- Windows、Linux 的原生化；这两个平台继续用 Electron。
- 用 Swift 重写运行时。
- 新业务功能。原生版先追平现有功能再扩展。
- 让快捷指令、通知或菜单栏直接执行项目命令或授予信任。
