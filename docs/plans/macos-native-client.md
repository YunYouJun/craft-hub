# macOS 原生客户端目标

日期：2026-10-22。状态：目标已提出；架构决定见 [ADR 0012](../adr/0012-make-a-macos-native-client-the-primary-desktop-host.md)，仍为 proposed。`apps/macos` 已有可运行原型，各平台正式发布的仍是 Electron。

## 继续实施 Goal（2026-10-22）

交付一个可供维护者日常使用和独立验收的 Craft Hub macOS 原生候选版：在现有 SwiftUI、WKWebView 和共享 TypeScript sidecar 上补齐宿主能力、实时同步、高频原生页面与系统入口，完成数据迁移和分发所需的工程实现，并提供 Release App、测试结果、性能对比和迁移回退演练记录。

本 Goal 的工程交付与下文“切换完成”分别验收。连续两周日用需要维护者的实际记录；正式签名、公证需要可用的发布身份；发布和替换默认安装需要明确授权。缺少这些条件时，继续完成可独立验证的实现，并如实保留待验收项，不能把本地构建通过写成正式切换完成。

阶段内按“实现一条用户流程 → 自动化验证 → Release App 实测 → 更新证据”推进。已有命令面板和快速记录作为回归基线；只有发现缺口时才修改。每轮先检查工作区，保留现有未提交改动；需要分支隔离时从当前工作状态承接，避免从旧主线丢失原生实现。

## 当前实现（2026-10-22）

已完成 SwiftUI 侧栏、工具栏、菜单和 WKWebView 宿主，共用 TypeScript 宿主后端。原生开发环境页可检查工具状态、版本、路径与当前 Node；原生软件中心可搜索、筛选未检测到的软件并按目录 ID 打开应用。配置、安装和来源管理通过完整网页工作台继续使用，工具栏可返回原生列表。

原生请求使用父进程管道下发的独立、仅存内存的 API token；网页继续使用单次引导和会话 cookie。启动有超时与握手大小限制，旧进程回调隔离，崩溃后最多自动恢复两次。`./script/build_and_run.sh --verify` 和 Codex Run 按钮共用构建启动流程。

这些实现尚不代表 M0 全部决策或 M1 日用验收完成。当前原型最低 macOS 15、独立应用身份和数据目录；正式迁移、签名、公证与默认宿主切换仍待完成。命令面板和快速记录已接入独立原生面板；事件流同步仍未实现。

原生环境/软件页前一轮验证：`pnpm lint`、`pnpm typecheck`、`pnpm test --run`（6019 项通过，9 项跳过）、`pnpm build` 和 Swift 测试（13 项）通过。Release `.app` 已实测环境检查、软件搜索与未检测到筛选、打开已安装应用、进入完整管理页与返回列表、辅助进程崩溃后恢复到原生页面。正常退出和强制退出后均确认原辅助进程退出；这只是本轮本机验证，尚未完成持续日用和性能验收。

本轮新增：⌘K 原生命令面板可筛选页面、项目、命令和技能，支持插件页面及键盘选择；选中命令仅进入现有详情页。⇧⌘Space 原生快速记录复用运行时的日期解析、AI 理解、To Do 连接与幂等创建。草稿和请求 ID 在本机原子持久化，损坏文件须先备份再恢复，主窗口关闭与辅助进程重连不销毁草稿。系统输入法组词期间的方向键和回车交给输入法处理。

原生面板验证进度：`pnpm lint`、`pnpm typecheck`、`pnpm build` 和 Release `.app` 构建通过；Swift 测试 25 项通过，全量 TypeScript 测试 6026 项通过、9 项跳过。已在真实 App 验证 ⌘K 搜索、方向键/回车跳转、⇧⌘Space 打开并直接输入、中文日期/重要标记解析、手工标题/备注在关闭重开后保留，以及启用自带 To Do 插件并重启运行时后保留完整草稿。

实测修复：相同输入在失焦时重复提交不再重置已核对的草稿；首次打开输入框延后到窗口建立后聚焦；主场景改为固定值 `WindowGroup`，防止关闭主窗口退出进程；同一运行时内复用临时网页会话，避免重开窗口出现访问拒绝。已在真实 App 确认关闭主窗口后进程仍在，重新打开的网页正常加载。插件管理只允许切换随 App 提供的可选插件，不开放任意模块加载；重启会拒绝中断正在运行的命令、Agent 任务和快速记录保存。

独占验收补充：用户授权 To Do 新增后，用原生面板的 ⌘Return 创建一条无截止日期、无提醒、非重要的“Craft Hub 原生验收”，保存回执出现且输入清空；经命令面板进入 To Do 页面，在“任务”列表筛选回读到唯一一条记录。测试待办保留，未完成或删除。随后使用另一份仅存本机的草稿，分别强制终止辅助进程、强制退出整个 App；重新连接或启动后，原文、标题、列表、日期、重要/提醒标记和手工备注全部保留，旧辅助进程已退出。恢复验收用本地草稿已清空。

通过原生目录选择器添加 `examples/sample-project` 后，⌘K 搜索 `Sample:hello` 并回车，只打开命令审阅页，显示实际命令与工作目录，保留“检查信任并运行”入口且无执行输出；项目仍未信任。主窗口关闭后，用户在其他 App 中实际按 ⇧⌘Space，确认快速记录弹出并能直接输入；验收工具随后确认该面板，再按 ⌘K 搜索项目命令，成功重开主窗口并定位到 `hello` 审阅页，网页会话有效。上述检查不代表下方持续日用或性能验收完成。

## 目标

让 macOS 原生客户端成为维护者日常使用的主力宿主。打开 Craft Hub、找到项目、记下一件事、启动工具，这几件最常做的事要和系统自带应用一样顺手；运行时、项目信任与执行边界保持不变。

**切换完成**同时满足以下三条：

1. 维护者连续两周只用原生版作为日常宿主，没有因为缺少功能或体验问题退回 Electron。
2. 下文的交互验收全部通过，未通过项有书面豁免理由。
3. macOS 上默认安装和打开的是原生版，Electron 版只作备用。

### 系统行为一致

- [ ] **窗口：** 记住位置和大小，支持全屏和多显示器；关闭最后一个窗口时按 macOS 惯例保留应用和菜单栏入口。
- [ ] **键盘：** 主流程能只用键盘完成；侧栏可用方向键移动；有标准菜单项和快捷键（⌘, 打开设置、⌘W、⌘F 等）；Esc 关闭面板和弹层。
- [ ] **菜单：** 应用菜单、右键菜单和 Dock 菜单都是原生菜单。
- [ ] **文字输入：** 中文输入法的候选框位置正确，支持撤销、重做和拼写检查。
- [ ] **拖放：** 把文件夹拖到侧栏或 Dock 图标上即添加项目，新项目仍为 `untrusted`。
- [ ] **外观：** 跟随系统的深浅色和强调色；遵守“减少透明度”“减少动态效果”“增强对比度”。
- [ ] **无障碍：** VoiceOver 能读出全部控件，焦点顺序与视觉顺序一致。

### 系统入口

- [ ] **菜单栏：** 常驻入口显示今日重点、快速记录和最近项目。
- [x] **全局快速记录：** 不用切换到主窗口就能记录。2026-10-22 用户真实键盘复核通过。
- [ ] **App Intents：** 提供“打开项目”和“快速记录”，可在快捷指令和 Spotlight 中使用。
- [ ] **通知：** 带操作按钮，但只能打开对应页面，不能授予信任或运行命令。
- [ ] **深链接：** `craft-hub:` 继续只做导航，见 [ADR 0007](../adr/0007-keep-desktop-links-navigation-only.md)。

### 可靠性与安全

- [x] 运行时辅助进程崩溃后自动重启，界面显示状态，未保存的快速记录不丢失。2026-10-22 Release App 强制终止辅助进程后复核通过。
- [ ] 正常退出和强制退出后都不残留 Node 进程。
- [ ] 优先使用本机已有的兼容 Node；诊断中心显示当前使用的 Node 路径和版本。用户升级或删除 Node 后，下次启动自动重新选择并提示。
- [ ] 固定规则找不到兼容 Node 时，引导页提供“从登录 shell 读取 PATH”按钮，照顾只靠 shell 启动文件配置的 nvm、Volta、asdf、mise。只有用户点击才会运行，启动时从不自动运行。运行一次登录 shell，非交互并设超时，只读取 `PATH`。找到的 Node 同样做兼容检查，并保存为用户指定路径，之后不再运行 shell。按钮旁说明这会执行用户的 shell 启动文件。
- [ ] 没有兼容 Node 时，原生引导页仍能打开并说明原因，满足 [ADR 0011](../adr/0011-focus-on-machine-setup-and-environment.md)。用户确认后才下载 Craft Hub 私有 Node 并校验官方 checksum；不修改用户自己的 Node 或 `PATH`。
- [ ] 原生端不执行项目命令。新项目仍为 `untrusted`，执行仍走运行时的显式信任和 `shell: false`；快捷指令、通知和菜单栏入口都不能绕过应用内确认。

**退出条件：** M1 结束时，以下任一项无法在一个迭代内解决，就暂停原生路线，回到“Electron 加 CSS”的改进方向，并在 ADR 0012 记录原因：

- 冷启动明显慢于 Electron 基线。
- 运行时辅助进程无法稳定退出，或在支持的 Node 版本上表现不一致。
- 原生外壳和网页内容之间的接缝严重影响日用。

## 不在本目标内

- Windows、Linux 的原生化；这两个平台继续用 Electron。
- 用 Swift 重写运行时。
- 新业务功能。原生版先追平现有功能再扩展。
- 让快捷指令、通知或菜单栏直接执行项目命令或授予信任。
